# Svelte

Example [Svelte](https://svelte.dev/) app. Svelte is a UI framework that compiles components into small, fast JavaScript at build time.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — Railpack build |
| Single-page application (SPA) | off |
| Project directory | `/` |
| Output directory | `/dist` |
| Install command | leave empty |
| Build command | leave empty |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production with minification
npm run build
```

Requires Node.js 20.19 or later (in the 22 branch — 22.12 or later).
